# ARTEx

한국어 · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh.md)

**ARTEx**는 Go 서비스와 Next.js 웹 인터페이스로 구성된 로컬 배포형 보안 진단 플랫폼입니다. 이 저장소는 GitHub 공개를 위해 정리한 소스 스냅샷입니다.

> ARTEx는 본인이 소유·운영하거나 점검에 대한 명시적인 서면 허가를 받은 시스템에서만 사용하세요. 요청을 보낼 수 있는 기능을 활성화하기 전에 격리된 실습 환경(예: OWASP Juice Shop)부터 사용하고, 승인된 범위를 정의하고 확인하세요.

## 목적 및 책임

이 프로젝트는 증가하는 침해 사고에 대비해, 본인이 개발·운영하거나 명시적으로 점검 권한을 받은 서비스의 자체 보안 진단, 유지보수 및 침해사고 대응 준비를 지원하기 위한 것입니다. 본인이 소유·운영하거나 사전에 서면 승인을 받은 시스템에서, 승인된 범위 안에서만 사용해야 합니다. 업무 목적으로 사용할 경우 소속 조직의 정책과 승인을 확인해야 합니다. 공개 또는 다운로드는 제3자 시스템을 점검할 권한을 부여하지 않습니다.

사용자는 대상 선정, 허가 취득과 확인, 범위 및 안전장치 설정, 관련 법률과 제3자 약관 준수, 사용으로 인한 결과에 대해 책임집니다. 관리자는 사용자의 활동을 지시·승인·감시하거나 보증하지 않으며, 배포 후 사용을 통제하지 않습니다.

소프트웨어는 적용 가능한 법률이 허용하는 최대 범위에서 어떠한 보증도 없이 **“있는 그대로(AS IS)”** 제공됩니다. 같은 범위에서 관리자는 소프트웨어의 사용 또는 사용 불능으로 발생하는 청구, 손실 또는 손해에 대한 책임을 부인합니다. 이 고지는 법적으로 배제할 수 없는 책임을 배제하거나, 포함된 라이선스 또는 적용 법률이 정한 권리와 의무를 변경하지 않습니다.

이 고지는 프로젝트가 의도하는 책임 배분을 설명할 뿐이며, 관리자가 조사·소송을 당하거나 책임을 지지 않는다고 보장하지 않습니다. 법적 결과는 사실관계, 관할권, 행위 및 적용 법률에 따라 달라집니다. 이 소프트웨어를 공개했다고 해서 사용이 허가되는 것은 아닙니다.

## 포함 내용

- Go 서비스와 관련 패키지
- Next.js 웹 클라이언트
- Docker Compose 배포 설정과 개발 스크립트
- 예제 설정 파일 및 저장소의 AGPL-3.0 라이선스

실행 데이터베이스, 로컬 자격 증명, `.env` 파일, 로그, 생성된 빌드 결과물 및 진단 대상별 자료는 포함하지 않습니다. `.env.example`에는 자리표시자만 있습니다. 서비스를 시작하기 전에 직접 배포 설정을 구성하세요.

## Docker Compose로 실행

1. Compose를 지원하는 Docker Desktop을 설치합니다.
2. `.env.example`을 `.env`로 복사하고 `POSTGRES_PASSWORD`를 강력한 로컬 값으로 바꿉니다. ARTEx 자체 LLM 기능을 사용할 때만 LLM 제공자 키를 추가합니다.
3. `docker compose up -d`를 실행합니다.
4. `http://127.0.0.1:8787`을 엽니다.

Compose 파일은 기본적으로 게시된 ARTEx 컨테이너 이미지를 사용합니다. 이 소스 스냅샷을 직접 빌드하려면 포함된 Dockerfile과 빌드 스크립트를 따르고 설정을 검토하세요. 적절한 인증, 네트워크 제한 및 운영상 안전장치 없이 서비스를 공개 네트워크에 노출하지 마세요.

## 개발

소스에는 Go 및 웹 클라이언트 프로젝트가 있습니다. 프로젝트별 개발 절차는 `go.mod`, `web/` 패키지 스크립트, `build.sh`, `dev.sh`를 확인하세요. 필요한 도구 버전과 빌드 방식은 달라질 수 있으므로 실제 프로젝트 파일에서 확인하세요.

## Claude Desktop 연동

Claude Desktop 연동 저장소에는 로컬 MCP 도구를 한 번에 설치하는 `.mcpb` 데스크톱 확장과 역할·스킬 Cowork 플러그인이 별도로 제공됩니다. 확장은 ARTEx 주소와 계정 설정을 받아 이 서버에 연결하지만, ARTEx 서버를 설치하거나 시작하지는 않습니다. [ARTEx Claude 연동](https://github.com/khsqowp/artex-integration) 안내를 따르세요.
