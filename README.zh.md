# ARTEx

## 使用 Docker Compose 运行

1. 安装支持 Compose 的 Docker Desktop。
2. 将 `.env.example` 复制为 `.env`，并把 `POSTGRES_PASSWORD` 改为强度足够的本地密码。只有在使用 ARTEx 自带的 LLM 功能时才添加 LLM 服务商密钥。
3. 运行 `docker compose up -d`。
4. 打开 `http://127.0.0.1:8787`。

Compose 文件默认使用已发布的 ARTEx 容器镜像。如需自行构建此源代码快照，请遵循随附的 Dockerfile 和构建脚本，并检查相关配置。未配置适当的身份验证、网络限制和运维安全措施前，请勿将服务暴露到公共网络。
