## Docker Compose で起動

1. Compose 対応の Docker Desktop をインストールします。
2. `.env.example` を `.env` にコピーし、`POSTGRES_PASSWORD` を強力なローカル値に変更します。ARTEx のネイティブ LLM 機能を使う場合に限り、LLM プロバイダーのキーを追加します。
3. `docker compose up -d` を実行します。
4. `http://127.0.0.1:8787` を開きます。

Compose ファイルは既定で公開済み ARTEx コンテナイメージを使用します。このソーススナップショットを自分でビルドする場合は、同梱の Dockerfile とビルドスクリプトに従い、設定を確認してください。適切な認証、ネットワーク制限、運用上の安全策を追加せずにサービスを公開ネットワークへ公開しないでください。

## Claude Desktop 連携

Claude 連携リポジトリでは、ローカル MCP ツールをまとめてインストールする `.mcpb` デスクトップ拡張と、役割プロファイル・スキル用の Cowork プラグインを別々に提供します。拡張機能は設定済みの ARTEx URL とアカウントを使ってこのサーバーに接続しますが、ARTEx サーバーをインストール・起動するものではありません。[ARTEx Claude 連携](https://github.com/khsqowp/artex-integration)の手順を参照してください。
